# Content Relevance Scoring Algorithm

This example demonstrates a simplified algorithm for scoring content relevance based on target keywords, density, and length. It illustrates how computer science principles like algorithmic thinking and data analysis can be applied to understand and optimize content for search engines, moving beyond surface-level SEO tactics.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
